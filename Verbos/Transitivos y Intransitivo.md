Dentro del japones para declarar cuando un objeto realiza la acción por su cuenta, se usa los verbos intransitivos. 
> En español estos verbos son los que se usan con "se" (Ejem: Se baño, Se callo).

En su escritura se usa el mismo kanji sin embargo su pronunciación cambia (**_QUE HUEVA_**) EN conjunto con su hiragana. Teniendo lo siguiente:
[[Verbos]]

| Transitive |                | Intransitive |                |
| ---------- | -------------- | ------------ | -------------- |
| 落とす        | caer           | 落ちる          | se callo       |
| 出す         | salir          | 出る           | se salio       |
| 入れる        | entrar         | 入る           | se metio       |
| 開ける        | abrir          | 開く           | se abrio       |
| 閉める        | cerrar         | 閉まる          | se cerro       |
| つける        | prender(wierd) | つく           | se prendio     |
| 消す         | to erase       | 消える          | se desaparecio |
| 抜く         | to extract     | 抜ける          | se extrajo     |
Lo importante es el énfasis que tiene cada verbo y si se usa la partícula [[を]] o la partícula [[が]] - [[は]].
Ejemplos:
1. 私が電気_を_つけた。  
    Prendí las luces
2. 電気_が_ついた。  
    Se prendieron las luces
3. 電気_を_消す。  
    Apaga las luces
4. 電気_が_消える。  
	 Se apagaron las luces
5. 誰が窓_を_開けた？  
    Quien abrió las ventanas
6. 窓_が_どうして開いた？  
    Porque se abrieron las ventanas
_Igual que en el español, cada forma da énfasis en la acción o en quien realiza la acción_
>**Dato curioso:** En japonés es muy común usar el intransitivo para evitar "culpar" a alguien. Si rompes una taza, es más educado decir "la taza se rompió" (intransitivo) que "yo rompí la taza" (transitivo).
