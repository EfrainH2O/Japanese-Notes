*Adjetivos en terminacion い*
Estos son los faciles de asmiliar, puesto que literlamente tienen el caracter い despues de ser usados, ejemplo 「嫌い」. En este caso este es un い-adjetivo. El punto de estos adjetivos es que su kanji no cambie para poder conjugarlo, por lo tanto de a fuerzas tienen que tener es caracter de い. 


**Remember how the negative state-of-being for nouns also ended in 「い」 (じゃない)? Well, just like the negative state-of-being for nouns, you can never attach the declarative 「だ」 to i-adjectives.**
#### Conjugacion:
|          | Positivo | Negativo |
| -------- | -------- | -------- |
| Presente | 高い       | 高くない     |
| Pasado   | 高かった     | 高くなかった   |
