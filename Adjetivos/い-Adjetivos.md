*Adjetivos en terminación い*
Estos son los fáciles de asimilar, puesto que literalmente tienen el carácter い después de ser usados, ejemplo 「嫌い」. En este caso este es un い-adjetivo. El punto de estos adjetivos es que su kanji no cambie para poder conjugarlo, por lo tanto de a fuerzas tienen que tener es carácter de い. 


**Remember how the negative state-of-being for nouns also ended in 「い」 (じゃない)? Well, just like the negative state-of-being for nouns, you can never attach the declarative 「だ」 to i-adjectives.**
#### Conjugación:
|          | Positivo | Negativo |
| -------- | -------- | -------- |
| Presente | 高い       | 高くない     |
| Pasado   | 高かった     | 高くなかった   |
