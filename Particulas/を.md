### Pronunciacion
Pronunciación formal en el habla es /o/.
### Funcion
Se usa para declarar el objeto directo. Osea a quien recae la acción. 
___
Tipo:
	*魚を食べる ->  Como pescado
	ジュースを飲んだ　-> Tome jugo.*
### Consideracion
Algo a considerar, es que se pueden usar para expresar en donde se ejecuta la acción, solo cuando el verbo se pueda y que la intención sea decir acción se ejecuta "en" (lugar).
___
Se entiende mejor con ejemplos:
1. 街_を_ぶらぶら歩く。  
    Aimlessly walk through town. (Lit: Aimlessly walk town)
2. 高速道路_を_走る。  
    Run through expressway. (Lit: Run expressway)
