Cuando el lugar tanto es el lugar como el tópico, se puede usar las dos a la vez y no hay problema. 　「[[に]]」y 「[[で]]」con  「[[は]]」
Ejemplo:
	1. ボブ：学校に行った？  
	Bob: (Did you) go to school?
	2. アリス：行かなかった。  
	Alice: Didn’t go.
	3. ボブ：図書館_には_？  
	Bob: What about library?
	4. アリス：図書館_にも_行かなかった。  
	Alice: Also didn’t go to library.

_In this example, Bob brings up a new topic (library) and so the location becomes the topic. The sentence is actually an abbreviated version of 「図書館には行った？」 which you can ascertain from the context._
Sin embargo la union de [[を]] y de は esa si no es posible. Siendo que no tiene sentido decir que el objeto indirecto es el tema, si de por si es **indirecto**.
