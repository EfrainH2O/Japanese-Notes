## Añadir tono de duda
Dentro del español se tiene (o bueno, por mi parte) el uso de *"es que..."*, que funciona para dar una especie de explicación. Dentro del ingles. el libro usa del ingles el *"the thing is..."*, que da la misma impresión.
> Mas fun fact para cuando se quiera traducir. Cuando no este solo en una sola oración. Pero cuando esto se usa con un verbo, es para cuando hablas del porque de algo. Ejemp: "fui al super para comprar huevos"

O de manera inversa, cuando quieres buscar explicación o comprobación de factos se usa la palabra *"verdad?"*, *"right?"*
El punto es que para dar ese énfasis, se usa la partícula の (なの para sustantivos) (y si es que tiene algo en seguida, se abrevia el の a ん).

| Tipo             | Terminacion |
| ---------------- | ----------- |
| Sustantivo       | なの          |
| Adjetivo / Verbo | の           |

#### Ejemplo:
- 今は忙しい_の_。  
    The thing is that (I’m) busy now.
	*Es que* hoy estoy ocupado.
	- **Vatos:** Para dar ese énfasis masculino (o en algunos casos de anime se añade el だy se deja igual para mujeres)
	 ==今は忙しい_のだ_==。  
	 * **Preguntas:** Por otra parte la pregunta se mantiene igual, independientemente del sexo, debido a que no se puede usar だ en preguntas.
	 ==今は忙しい_の_？==
	 Is it that (you) are busy now? 
	 estas ocupado hoy *verdad*?
> Esta partícula a diferencia de las demás si se puede conjugar como si fuera un [[Sustantivos| sustantivo]] por lo que puede tener una tabla de conjugaciones curiosas.
