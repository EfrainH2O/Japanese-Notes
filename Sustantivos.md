Conjugacion de sustantivos.

|          | Positivo   | Negativo |
| -------- | ---------- | -------- |
| Presente | 学生　（[[だ]]） | 学生じゃない   |
| Pasado   | 学生だった      | 学生じゃなかった |
Dentro del japones, no hay verbo de ser o estar como en los idiomas de lenguas romances. Por tanto para describir como algo es, solamente se dice asi nomas. Sin embargo para poder saber a que se refiere dicho adjetivo o sustantivo, se requiere el uso del contexto o de la particula [[は]] .
